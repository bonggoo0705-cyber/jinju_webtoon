# 스토리 및 대사

> 회차별 이야기, 역사 근거, 컷 구성, 대사를 관리합니다. 캐릭터 이름과 외형은 `02-캐릭터-설정.md`를 따른다는 전제입니다.

## 작성 규칙

- 화마다 사건명·시기·출처를 먼저 기록한다.
- 대사 앞에는 반드시 `CHAR_A`, `CHAR_B`를 붙인다.
- 한 컷에서는 하나의 핵심 정보 또는 감정만 전달한다.
- 역사적 사실이 아닌 설화·추정은 `※`로 명시한다.
- 말투·호칭이 캐릭터 문서와 일치하는지 대사 완성 후 검수한다.
